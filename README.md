# ExitPass Assisted Payment Terminal

This repository contains the separate ExitPass Assisted Payment Terminal application.

Initial scope is Mode 1, `CASHIER_ASSISTED_TERMINAL`, for a Windows fixed-station cashier-assisted payment terminal. The terminal is a presentation and workflow surface for approved ExitPass APIs; it must not become a tariff, payment-finality, fiscal-numbering, direct database, Vendor PMS, or gate authority.

The first implementation branch will add the visible Mode 1 terminal shell.
